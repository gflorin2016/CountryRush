# Country Rush v5 - Android (APK)

## Cum obții APK-ul (o singură dată, gratuit, fără Android Studio)
1. Cont gratuit pe github.com -> "New repository" (privat) -> "uploading an existing file".
2. Încarcă TOT conținutul acestui folder (inclusiv folderul ascuns .github).
3. Tab "Actions" -> "Build APK" -> rulează (2-4 min).
4. Deschide rularea terminată -> jos "Artifacts" -> descarcă "CountryRush-v5-apk" (zip) -> scoate app-debug.apk.
5. Trimite APK-ul pe telefon, deschide-l (permite "instalare din surse necunoscute").

## Folosire
1. Cheie gratuită Euler Stream: eulerstream.com -> cont -> API key.
2. În aplicație: ⚙ Controls -> nume TikTok (fără @) + cheie -> Connect. Se salvează.
3. Pornește LIVE în TikTok (trebuie să fii LIVE ca să meargă conectarea), alege "Partajare ecran", apoi deschide aplicația Country Rush.
4. Apasă ⚙ Controls ca să ascunzi panoul înainte de a arăta ecranul.
